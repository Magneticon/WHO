# WHO
Windows version of z/OS TSO WHO command

This program will help you to find, what is holding files and folders and enable you to close open handles to it, like z/OS TSO WHO command would list users, who had a dataset open in exclusive mode.

And since on Windows there is no good alternative to track those programs, which are interfering with our file management attempts, the WHO utility comes handy.

It should work on Windows 2000+, with some luck on Windows NT 3.51 or NT 4.0, although these are untested.
